Smart Lamp Prototype

Two phones, one street lamp. Phone A reads the light, Phone B becomes the lamp — live over WebSocket.

Phone A

Sensor

Points its camera at the scene and streams a 0–100 luminance score every 500ms.


Open sensor
Phone B

Lamp screen

Goes fullscreen white (max brightness) when it's dark, off when it's bright.


Open lamp
Control logic

if luminance < 20 → lamp ON, screen brightness max
if luminance >= 20 → lamp OFF, screen brightness min
